## यह क्या करता है

यह 57 भाषाओं के बीच पाठ का अनुवाद करता है, जिसके लिए [TranslateGemma](https://ollama.com/library/translategemma) का उपयोग किया जाता है, जो आपके GPU पर [Ollama](https://ollama.com) के माध्यम से स्थानीय रूप से चलता है। कोई API कुंजी नहीं, कोई क्लाउड नहीं, कोई दर सीमा नहीं — डिफ़ॉल्ट रूप से सब कुछ आपके मशीन पर रहता है। आप एक रिमोट ओलामा का उपयोग करना चुन सकते हैं, जैसे कि [Ollama Cloud](#ollama-cloud-optional)।

## त्वरित शुरुआत

### 1. ओलामा स्थापित करें

[ollama.com](https://ollama.com) से डाउनलोड करें और इसे शुरू करें:

```bash
ollama serve
```

### 2. एक मॉडल डाउनलोड करें

```bash
ollama pull translategemma:27b   # 17 GB  — the default, highest quality
# or
ollama pull translategemma:12b   # 8.1 GB — faster, for GPUs with less VRAM
# or
ollama pull translategemma:4b    # 3.3 GB — fastest, lower quality
```

> **सुझाव:** आप इस चरण को छोड़ सकते हैं — पॉलीग्लॉट पहली बार उपयोग करने पर डिफ़ॉल्ट मॉडल (27B, 17 GB) को स्वचालित रूप से डाउनलोड करता है। एक छोटे GPU पर, पहले `POLYGLOT_MODEL=translategemma:12b` सेट करें (देखें [कॉन्फ़िगर करने योग्य डिफ़ॉल्ट मॉडल](#configurable-default-model))।

### 3. अपने MCP क्लाइंट में जोड़ें

**Claude Code / Claude Desktop** — `claude_desktop_config.json` या `.mcp.json` में जोड़ें:

```json
{
  "mcpServers": {
    "polyglot": {
      "command": "npx",
      "args": ["-y", "@mcptoolshop/polyglot-mcp"]
    }
  }
}
```

**स्रोत से:**

```bash
git clone https://github.com/mcp-tool-shop-org/polyglot-mcp.git
cd polyglot-mcp
npm install && npm run build
node dist/index.js
```

बस इतना ही। क्लाउड से कुछ अनुवाद करने के लिए कहें और यह स्वचालित रूप से `translate` टूल का उपयोग करेगा।

## उपकरण

पॉलीग्लॉट छह MCP उपकरण प्रदान करता है:

### `translate`

समर्थित किसी भी भाषा जोड़ी के बीच पाठ का अनुवाद करें।

| पैरामीटर | आवश्यक | विवरण |
|-------------|----------|-------------|
| `text`      | हाँ | अनुवाद करने के लिए पाठ |
| `from`      | हाँ | स्रोत भाषा कोड या नाम (जैसे, `en`, `English`) |
| `to`        | हाँ | लक्ष्य भाषा कोड या नाम (जैसे, `ja`, `Japanese`) |
| `model`     | no       | ओलामा मॉडल (डिफ़ॉल्ट: `translategemma:27b`) |
| `glossary`  | no       | कस्टम शब्द `{"source": "translation"}` के रूप में ओवरराइड करता है — अंतर्निहित सॉफ़्टवेयर शब्दावली के साथ मिलाया जाता है |

लंबे पाठ को स्वचालित रूप से पैराग्राफ और वाक्य सीमाओं पर खंडों में विभाजित किया जाता है, क्रम में अनुवाद किया जाता है, और फिर से जोड़ा जाता है। सभी अनुवादों को गुणवत्ता के लिए मान्य किया जाता है (खाली आउटपुट, इको डिटेक्शन, ट्रंकेशन, गड़बड़ पाठ)।

### `translate_markdown`

संरचना को बनाए रखते हुए पूरे मार्कडाउन दस्तावेज़ का अनुवाद करें। कोड ब्लॉक, HTML तत्व, बैज, URL और तालिका स्वरूपण को बरकरार रखा जाता है — केवल गद्य सामग्री (शीर्षक, पैराग्राफ, टैगलाइन, तालिका कोशिकाएं) का अनुवाद किया जाता है। इनलाइन कोड स्पैन का अनुवाद से पहले प्लेसहोल्डर से बदल दिया जाता है और बाद में पुनर्स्थापित कर दिया जाता है, ताकि कमांड, ध्वज, पैकेज नाम और पहचानकर्ता ठीक वैसे ही वापस आएं जैसे वे लिखे गए थे।

| पैरामीटर | आवश्यक | विवरण |
|-------------|----------|-------------|
| `markdown`  | हाँ | अनुवाद करने के लिए पूरी मार्कडाउन सामग्री |
| `from`      | हाँ | स्रोत भाषा कोड या नाम |
| `to`        | हाँ | लक्ष्य भाषा कोड या नाम |
| `model`     | no       | ओलामा मॉडल (डिफ़ॉल्ट: `translategemma:27b`) |

### `list_languages`

अपने कोड के साथ सभी 57 समर्थित भाषाओं को सूचीबद्ध करें।

### `check_status`

जांचें कि ओलामा चल रहा है या नहीं और कौन से TranslateGemma मॉडल स्थापित हैं। यदि ओलामा नहीं चल रहा है तो यह स्वचालित रूप से शुरू करने का प्रयास करता है।

### `translate_all`

एक ही समय में कई भाषाओं में मार्कडाउन सामग्री का अनुवाद करें (डिफ़ॉल्ट: 7 — जापानी, चीनी, स्पेनिश, फ्रेंच, हिंदी, इतालवी, पुर्तगाली)। GPU-सुरक्षित सेमाफोर लिमिटिंग के साथ अनुवादों को एक साथ चलाता है।

| पैरामीटर | आवश्यक | विवरण |
|---------------|----------|-------------|
| `markdown`    | हाँ | अनुवाद करने के लिए पूरी मार्कडाउन सामग्री |
| `from`        | no       | स्रोत भाषा कोड (डिफ़ॉल्ट: `en`) |
| `languages`   | no       | लक्ष्य भाषा कोड की सरणी (डिफ़ॉल्ट: सभी 7) |
| `model`       | no       | ओलामा मॉडल (डिफ़ॉल्ट: `translategemma:27b`) |
| `concurrency` | no       | अधिकतम समवर्ती अनुवाद (डिफ़ॉल्ट: 2, अधिकतम: 3) |
| `navBar`      | no       | भाषा नेविगेशन बार इंजेक्ट करें (डिफ़ॉल्ट: सही) |

### `translate_readme`

एक README.md **फ़ाइल** का उसी 7 भाषाओं में अनुवाद करें और `README.<lang>.md` फ़ाइलों को इसके बगल में लिखें, स्रोत README और प्रत्येक अनुवाद में भाषा नेविगेशन बार को ताज़ा करें। यह अनुवादित पाठ के बजाय प्रति-भाषा स्थिति सारांश (ठीक/विफल, समय, लिखी गई फ़ाइलें) लौटाता है; जब आप सामग्री वापस चाहते हैं तो `translate_markdown` का उपयोग करें।

| पैरामीटर | आवश्यक | विवरण |
|---------------|----------|-------------|
| `readmePath`  | हाँ | स्रोत README.md का पूर्ण पथ |
| `tier`        | no       | `quality` (`translategemma:27b`, डिफ़ॉल्ट), `bulk` (`12b`), या `draft` (`2b`); जब `model` सेट होता है तो अनदेखा किया जाता है |
| `model`       | no       | स्पष्ट ओलामा मॉडल; `tier` को ओवरराइड करता है |
| `languages`   | no       | लक्ष्य भाषा कोड का सबसेट (डिफ़ॉल्ट: सभी 7) |
| `concurrency` | no       | अधिकतम समवर्ती अनुवाद (डिफ़ॉल्ट: 2, अधिकतम: 3) |
| `navBar`      | no       | भाषा नेविगेशन बार इंजेक्ट करें या ताज़ा करें (डिफ़ॉल्ट: सही) |

## विशेषताएं

### स्वचालित रूप से शुरू और स्वचालित रूप से डाउनलोड
यदि ओलामा नहीं चल रहा है तो यह स्वचालित रूप से शुरू हो जाता है। यदि TranslateGemma मॉडल स्थापित नहीं है तो यह स्वचालित रूप से डाउनलोड हो जाता है। कोई मैन्युअल सेटअप आवश्यक नहीं है।

### घातीय बैकऑफ़ के साथ पुनः प्रयास करें
अस्थायी ओलामा विफलताएं (नेटवर्क में रुकावट, अस्थायी अधिभार) स्वचालित रूप से 2 बार तक घातीय बैकऑफ़ (1 सेकंड, 2 सेकंड) के साथ पुनः प्रयास की जाती हैं। गैर-पुनः प्रयास करने योग्य त्रुटियां (खराब मॉडल नाम, अमान्य इनपुट) तुरंत विफल हो जाती हैं।

### स्मार्ट चंकिंग
लंबे पाठ को प्राकृतिक सीमाओं पर विभाजित किया जाता है — पैराग्राफ, फिर वाक्य — ताकि अनुवाद संदर्भ को संरक्षित किया जा सके। खंड आकार मॉडल के अनुकूल होते हैं: 2B/4B मॉडल के लिए 2K वर्ण, 12B के लिए 4K, 27B के लिए 6K।

### खंड कैश
अनुवादित खंडों को सामग्री हैश (स्रोत पाठ + लक्ष्य भाषा + मॉडल का SHA-256) द्वारा कैश किया जाता है। अपरिवर्तित खंड पूरी तरह से पुनः अनुवाद को छोड़ देते हैं, इसलिए संपादन के बाद अनुवाद को फिर से चलाने से केवल वही बदलता है जो बदला है। कैश स्रोत फ़ाइल के बगल में `.polyglot-cache.json` में 30-दिन की TTL के साथ रहता है। इसका उपयोग `translateMarkdown` लाइब्रेरी API द्वारा तब किया जाता है जब `filePath` दिया जाता है (और रिपॉजिटरी के `scripts/translate-*.mjs` CLI द्वारा); MCP उपकरण इसके बिना अनुवाद करते हैं।

कई रन एक ही कैश फ़ाइल साझा कर सकते हैं। प्रत्येक सहेजने से केवल अपनी ही परिवर्तन लॉक के तहत फ़ाइल में मर्ज होते हैं और फ़ाइल को परमाणु रूप से बदल देते हैं, इसलिए समानांतर में अनुवाद की गई भाषाएं एक-दूसरे की प्रविष्टियों को बनाए रखती हैं, और एक भाषा के लिए कैश को साफ़ करने से अन्य भाषाएं अप्रभावित रहती हैं।

### अनुवाद स्मृति (फ़ज़ी कैश)
जब सटीक कैश हिट नहीं मिलता है, तो एक कैश किए गए अनुवाद का पुन: उपयोग केवल तभी किया जाता है जब इसका स्रोत नए से केवल व्हाइटस्पेस लेआउट में भिन्न होता है: एक पंक्ति के भीतर रिक्ति, किसी भी छोर पर व्हाइटस्पेस, या CRLF बनाम LF। किसी भी अन्य संपादन को फिर से अनुवाद किया जाता है, जिसमें एक परिवर्तित शब्द, संख्या, विराम चिह्न, अक्षर मामला या इनलाइन कोड स्पैन शामिल है। एक कैश किए गए अनुवाद में इसके अपने स्रोत का अनुवाद होता है, इसलिए संपादित पाठ के लिए इसका पुन: उपयोग करने से पुरानी शब्दावली सामने आएगी।

### ओलामा क्लाउड (वैकल्पिक)
`OLLAMA_HOST` को `localhost:11434` के बजाय किसी अन्य ओलामा सर्वर पर अनुरोध भेजने के लिए सेट करें। [ओलामा क्लाउड](https://ollama.com) के लिए, `OLLAMA_API_KEY` भी सेट करें: कुंजी को एक बेयरर टोकन के रूप में भेजा जाता है, और केवल एक गैर-लूपबैक होस्ट पर।

```bash
OLLAMA_HOST=https://ollama.com OLLAMA_API_KEY=... npx @mcptoolshop/polyglot-mcp
```

### कंक्यूरेंसी सेमाफोर
सीमित वीआरएएम वाले सिस्टम पर जीपीयू ओओएम को रोकने के लिए सभी ओलामा कॉल को एक काउंटिंग सेमाफोर (डिफ़ॉल्ट सीमा: 1) द्वारा सुरक्षित किया जाता है। `POLYGLOT_CONCURRENCY` के साथ ओवरराइड करें:

```bash
POLYGLOT_CONCURRENCY=2 npx @mcptoolshop/polyglot-mcp
```

### एमसीपी प्रोग्रेस टोकन
जब क्लाइंट `progressToken` प्रदान करता है, तो सभी उपकरण एमसीपी `notifications/progress` के माध्यम से प्रगति की रिपोर्ट करते हैं। प्रति-चंक रिपोर्ट का अनुवाद करें, प्रति-खंड-बैच के लिए ट्रांसलेट_मार्कडाउन का अनुवाद करें, प्रति-भाषा के लिए ट्रांसलेट_ऑल का अनुवाद करें, और प्रति-चरण के लिए चेक_स्टेटस का अनुवाद करें।

### सॉफ्टवेयर शब्दावली
12 तकनीकी शब्दों (एपीआई, सीएलआई, एसडीके, आदि) की एक अंतर्निहित शब्दावली सॉफ्टवेयर शब्दावली के सुसंगत अनुवाद को सुनिश्चित करती है। कस्टम शब्दावली प्रविष्टियों को प्रति-अनुरोध पारित किया जा सकता है और डिफ़ॉल्ट के साथ मर्ज किया जाता है।

### बैच अनुवाद
`translateBatch` जहां संभव हो, कई खंडों को एक एकल प्रॉम्प्ट में समूहित करता है, जिससे राउंड-ट्रिप कम हो जाते हैं। यदि बैच विभाजक खराब हो जाता है, तो व्यक्तिगत अनुवाद पर वापस आ जाता है।

### कॉन्फ़िगर करने योग्य डिफ़ॉल्ट मॉडल
डिफ़ॉल्ट मॉडल `translategemma:27b` है। किसी अन्य मॉडल का उपयोग करने के लिए `POLYGLOT_MODEL` पर्यावरण चर सेट करें, उदाहरण के लिए, कम वीआरएएम वाले जीपीयू पर:

```bash
POLYGLOT_MODEL=translategemma:12b npx @mcptoolshop/polyglot-mcp
```

### संरचित त्रुटियां
सभी त्रुटियां `PolyglotError` का उपयोग करती हैं, जिसमें एक मशीन-पठनीय कोड (`MODEL_NOT_FOUND`, `OLLAMA_UNAVAILABLE`, `TRANSLATION_FAILED`, आदि), एक मानव-पठनीय संदेश, एक वैकल्पिक संकेत और एक `retryable` ध्वज होता है।

### आउटपुट सत्यापन
प्रत्येक अनुवाद को स्वचालित रूप से मान्य किया जाता है: खाली आउटपुट त्रुटि उत्पन्न करता है (पुन: प्रयास करने योग्य), स्रोत-पाठ प्रतिध्वनि को चिह्नित किया जाता है, गंभीर संक्षिप्तीकरण और भ्रमित करने वाली बातों को चेतावनी दी जाती है, खराब एन्कोडिंग और मॉडल मेटा-टिप्पणी का पता लगाया जाता है। चेतावनियां एमसीपी टूल प्रतिक्रिया में दिखाई देती हैं।

### स्ट्रीमिंग
`OllamaClient.generateStream()` एनडीजेएसओएन के माध्यम से टोकन उत्पन्न करता है क्योंकि ओलामा उन्हें उत्पन्न करता है। `translate()` फ़ंक्शन वास्तविक समय की प्रगति प्रदर्शन के लिए `onToken` कॉलबैक स्वीकार करता है। स्ट्रीमिंग और गैर-स्ट्रीमिंग दोनों पथों में पुन: प्रयास तर्क साझा होता है।

## सुरक्षा और डेटा दायरा

| पहलू | विवरण |
|--------|--------|
| **Data touched** | ओलामा एपीआई को भेजा गया पाठ - डिफ़ॉल्ट रूप से स्थानीय (`localhost:11434`), या यदि आपने एक सेट किया है तो होस्ट `OLLAMA_HOST` में। `.polyglot-cache.json` अनुवादित फ़ाइल के बगल में खंड कैश। |
| **Files written** | `translate_readme` आपके द्वारा पास किए गए रीडमी के बगल में `README.<lang>.md` लिखता है और उस रीडमी के भाषा नेविगेशन बार को ताज़ा करता है |
| **Data NOT touched** | कोई ब्राउज़र डेटा नहीं, कोई ओएस क्रेडेंशियल नहीं, ऊपर दिए गए निर्देशिकाओं के बाहर कुछ भी नहीं |
| **Network** | डिफ़ॉल्ट रूप से केवल `localhost:11434` पर एचटीटीपी - शून्य बाहरी आउटगोइंग। केवल तभी रिमोट जब `OLLAMA_HOST` कहीं और इंगित करता है |
| **Secrets** | यदि सेट है, तो `OLLAMA_API_KEY` को पर्यावरण से पढ़ा जाता है और केवल एक गैर-लूपबैक `OLLAMA_HOST` पर एक बेयरर टोकन के रूप में भेजा जाता है; कभी भी डिस्क पर नहीं लिखा जाता है या लॉग नहीं किया जाता है |
| **Telemetry** | कोई भी एकत्र या भेजा नहीं गया |

भेद्यता रिपोर्टिंग नीति के लिए [सुरक्षा.एमडी](SECURITY.md) देखें।
